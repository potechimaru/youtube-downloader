# YouTube Downloader GUI

YouTubeのURLを入力し、動画（MP4）または音声（MP3）として指定フォルダーへ保存するWindows向けアプリです。

## 必要環境

- Windows 10 / 11
- Python 3.10以降
- インターネット接続
- winget（FFmpegが未導入の場合）

## 起動方法

1. 初回のみ `setup.bat` をダブルクリックします。
2. Python仮想環境、yt-dlp、FFmpegの準備が完了するまで待ちます。
3. セットアップ後は `run.bat` をダブルクリックしてアプリを起動します。

yt-dlpを更新したい場合や依存関係に問題がある場合は、`setup.bat`を再実行してください。

## 使い方

1. YouTube動画のURLを貼り付けます。
2. 「参照...」から保存先フォルダーを選択します。
3. 「動画（MP4）」または「音声のみ（MP3）」を選択します。
4. 「ダウンロード開始」を押します。

動画はMP4を優先して利用可能な高画質で保存されます。音声は192 kbpsのMP3へ変換されます。プレイリストのURLを指定した場合も、対象の動画1本だけを保存します。

## 注意事項

- 著作権、YouTubeの利用規約、および各動画の利用条件を守り、ダウンロードが許可されたコンテンツだけに使用してください。
- 年齢制限、ログイン必須、地域制限、配信方式などにより保存できない動画があります。
- YouTube側の仕様変更で失敗する場合は、`setup.bat`を再実行してyt-dlpを更新してください。
